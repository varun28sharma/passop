## ⭐ Project Overview

PassOP is a simple, secure, and user-friendly password manager built with **React** and **Node.js**, using **MongoDB** as the database. It allows users to store, view, edit, and manage their passwords safely with encryption.

### 🔥 Key Features
- 🔒 **Securely store passwords** with strong encryption
- 💾 **Add Passwords** with website URL, username, and password fields
- 📝 **Edit Passwords** quickly and efficiently
- ❌ **Delete Passwords** when no longer needed
- 📋 **Copy to Clipboard** for fast access
- 👁️ **Show/Hide Passwords** for convenience

## 🚀 Getting Started

### 📌 Prerequisites
Ensure you have the following installed:
- [Node.js](https://nodejs.org/) (v14.x or higher)
- [npm](https://www.npmjs.com/)
- [Vite](https://vitejs.dev/) (for React front-end)
- [MongoDB](https://www.mongodb.com/) (local/cloud instance)

### 🔧 Installation

#### 1️⃣ Clone the Repository:
```bash
  git clone https://github.com/<your-username>/PassOP.git
  cd PassOP
```

#### 2️⃣ Setting Up the Backend:
```bash
  cd backend
  npm install
```
- Configure your `.env` file:
```env
  MONGO_URI=<your-mongodb-connection-string>
  DB_NAME=<your-database-name>
```
- Start the backend server:
```bash
  node server.js
```

#### 3️⃣ Setting Up the Frontend:
```bash
  cd ../frontend
  npm install
  npm run dev
```

#### 4️⃣ Access the Application:
Open your browser and visit: [http://localhost:3000](http://localhost:3000)
